# Upstream permission / การอนุญาตจากเจ้าของต้นฉบับ

On 25 October 2026, the owner of `BerlinoPotato/PDFStudio` approved the
request to publish this Apple Silicon macOS adaptation's source and `.app` / `.dmg`
packages on the `ozejet/PDFStudio` fork with attribution to the original project.

- Request and public approval: <https://github.com/BerlinoPotato/PDFStudio/issues/1>
- Initial approval comment: <https://github.com/BerlinoPotato/PDFStudio/issues/1#issuecomment-6395842358>
- AGPLv3 authorization: <https://github.com/BerlinoPotato/PDFStudio/issues/1#issuecomment-6397084771>
- Original project: <https://github.com/BerlinoPotato/PDFStudio>

The owner subsequently confirmed that PDFStudio code for which they hold copyright
may be distributed in this adaptation under GNU AGPL version 3, including source
and app packages, with corresponding source, preserved notices, credit, and a link
to the original repository. This does not change the original repository's license
or replace third-party obligations. PyMuPDF 1.28.0 is used under its GNU AGPLv3
option, with its exact source archive distributed beside the binaries.

เมื่อวันที่ 25 ตุลาคม 2026 เจ้าของ `BerlinoPotato/PDFStudio` อนุญาตคำขอให้เผยแพร่
source ของงานดัดแปลงสำหรับ Apple Silicon macOS และแพ็กเกจ `.app` / `.dmg`
บน fork `ozejet/PDFStudio` โดยให้เครดิตโปรเจกต์ต้นฉบับ

- คำขอและคำอนุญาตสาธารณะ: <https://github.com/BerlinoPotato/PDFStudio/issues/1>
- คอมเมนต์อนุมัติเริ่มต้น: <https://github.com/BerlinoPotato/PDFStudio/issues/1#issuecomment-6395842358>
- คำอนุญาต GNU AGPLv3: <https://github.com/BerlinoPotato/PDFStudio/issues/1#issuecomment-6397084771>
- โปรเจกต์ต้นฉบับ: <https://github.com/BerlinoPotato/PDFStudio>

เจ้าของยืนยันเพิ่มเติมว่าโค้ด PDFStudio ส่วนที่ตนถือสิทธิ์สามารถเผยแพร่ในงานดัดแปลงนี้
ภายใต้ GNU AGPLv3 ได้ ทั้ง source และแพ็กเกจแอป โดยเปิดเผย corresponding source
รักษาข้อความลิขสิทธิ์ ให้เครดิต และลิงก์กลับต้นฉบับ คำอนุญาตนี้ไม่เปลี่ยน license ของ
repo ต้นฉบับและไม่แทนเงื่อนไขของ dependency ภายนอก ส่วน PyMuPDF 1.28.0 ใช้ทางเลือก
GNU AGPLv3 และแนบ source archive ที่ตรงรุ่นไว้ข้าง binary
